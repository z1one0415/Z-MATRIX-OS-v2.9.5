### 3.2 真信号三要素 (基于10只验证)

```
✅ 要素1: 与核心业务直接关联
   ├─ 中联重科: 挖机数据→公司主营 → 100%真信号
   └─ 深粮控股: 粮食安全→公司主营相关性弱 → 29%真信号

✅ 要素2: 有可量化的财务/运营验证
   ├─ 云南铜业: 铜价上涨→Q1净利+212% → 可验证 → 75%真信号
   └─ 湖北宜化: 磷化工涨价→但净利-24% → 不可验证 → 50%真信号

✅ 要素3: 行业/宏观周期共振
   ├─ 中联重科: 出口+31.3% + 财政4.4万亿 → 三重共振 → 最强
   └─ 双汇发展: 分红+消费复苏弱 → 无共振 → 40%真信号
```

### 3.3 假信号四型态

| 型态 | 表现 | 典型案例 |
|:--|:--|:--|

| **基本面脱节型** | 热点题材但公司无法承接 | 湖北宜化(磷酸铁锂概念, 规模尚小) |

| **噪音污染型** | 小规模事件被市场忽略 | 深粮控股(东莞物流增资+0.8%/2日) |

**关键补充发现 (源于云南铜业/双汇发展对比研究)**:

周期股 vs 消费股的催化规律根本不同:
- **周期股**: "重市场不重财务" — 商品价格(S/A级)催化7-15%, 财报(B级)5-10%
- **消费股**: "重财务不重市场" — 财报(B级)催化2-5%, 分红公告是主要催化
- **认证型**: BNEF/Q1(+8.3%)→Q5(+0.5%) — 同质催化边际递减规律普适
- **订单型**: 单次中标催化5-7%, 中标量翻倍→窗口延长50%+
