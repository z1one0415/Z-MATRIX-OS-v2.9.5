# Agent Permission Policy

## Rules
- VIEW_ONLY agent calling R3 → REJECT
- R3+ requires human review
- R4/R5 requires human approval
- R9 always blocked

## Permission Levels
VIEW_ONLY | ANNOTATION_WRITER | CASE_DRAFT_WRITER | REPORT_DRAFT_WRITER | RESEARCH_DB_PROPOSER | CODE_PATCH_PROPOSER | VERIFY_RUNNER | RELEASE_PROPOSER
