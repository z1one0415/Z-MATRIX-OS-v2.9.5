# v3.0-alpha Integration Readiness Gate Architecture v1.0

## Goal

Establish the v3.0-alpha integration readiness gate.

## Check Chain

Workspace Alignment → EventStore → Hermes Memory Kernel → Approval Loop → Prompt Middleware → Tail-Risk Gates → System Controller

## Not In Scope

- No real trade
- No runtime enable
- No Hermes memory write
- No Z9 write
- No auto calibration
- No prompt auto injection
- No broker connection

## Constraints

v3.0-alpha readiness means: system foundation is ready for integration validation.
It does NOT mean: production ready, auto trade ready, prompt injection ready.
