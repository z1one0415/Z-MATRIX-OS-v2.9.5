## 目标

把 B/R/D/Risk/Regime/Sector/Cost 全部因子注册化，防止脚本野生增长。

只允许登记，不允许优化、不允许调权、不允许新增 alpha、不允许 production。

## FactorRegistryItem

```python
from pydantic import BaseModel
from typing import Literal

class FactorRegistryItem(BaseModel):
    factor_id: str
    factor_name: str
    matrix_layer: Literal["R", "B", "D", "Risk", "Regime", "Sector", "Cost", "Evidence"]
    data_source_id: str
    pit_safe: Literal["YES", "NO", "PARTIAL", "UNKNOWN"]
    frequency: str
    ttl_days: int | None = None
    trust_level: Literal["T0", "T1", "T2", "T3", "BLOCKED", "MISSING"]
    missing_policy: Literal["BLOCK", "DATA_INSUFFICIENT", "ALLOW_PROXY", "IGNORE"]
    usable_for_backtest: bool = False
    usable_for_current_snapshot: bool = False
    usable_for_paper: bool = False
    production_allowed: bool = False
    outcome_horizon_safe: bool = False
    net_return_ready: bool = False
    evidence_status_ready: bool = False
    promotion_status: str = "BLOCKED_BY_PLATFORM_PHASE"
```

## FactorPermissionGate

必须阻断：

```text
production_allowed=True
pit_safe=NO/UNKNOWN 且 usable_for_backtest=True
trust_level=BLOCKED/MISSING 但 promotion_status 不是 BLOCKED
缺 data_source_id
缺 missing_policy
```
