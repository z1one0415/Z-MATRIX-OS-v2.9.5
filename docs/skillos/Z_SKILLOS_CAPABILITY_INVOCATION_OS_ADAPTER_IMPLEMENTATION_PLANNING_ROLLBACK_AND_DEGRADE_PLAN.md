# Adapter Rollback And Degrade Plan
## Status: Z_SKILLOS_CAPABILITY_INVOCATION_OS_ADAPTER_ROLLBACK_AND_DEGRADE_PLAN_READY
Adapter rollback and degrade: adapter disabled fallback (return DENY_NOOP), docs-only fallback (return DEGRADE_DOCS_ONLY), evidence-only fallback (capture evidence, deny execution), manual review fallback (escalate to human), no-execution fallback (deny all capability calls), capability unavailable behavior (degrade to lower tier), emergency adapter kill switch (global disable).
