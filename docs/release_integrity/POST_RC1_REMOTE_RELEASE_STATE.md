## Distinction

```
Tag page ≠ formal GitHub Release

Tag pages are auto-generated by GitHub when an annotated tag is pushed.
A formal GitHub Release requires explicit creation via gh release create
or GitHub UI. The tag page exists but is NOT a published release.
```
