# ZC35 EVENT STUDY PROTOCOL V10

## Rules
1. Scheduled events (conferences, earnings dates, product launches)
   WITHOUT surprising announcements → DOWNGRADED to OBSERVE only
2. Process events (regulatory reviews, approvals, IPOs) 
   WITHOUT result announcement → DOWNGRADED to OBSERVE only
3. Cross-sector weak correlation events → NOT a catalyst
4. Entity relevance gate must be enabled
5. Event must have: publish_time, event_type, evidence_level, source

## Sell-on-News Defense
- Pre-event price run-up > threshold → SELL_ON_NEWS_RISK elevated
- Post-event residual power < 0.3 → signal expiry
- Scheduled meeting/roadshow/conference → zero catalyst value
  (only unexpected announcement during event counts)
