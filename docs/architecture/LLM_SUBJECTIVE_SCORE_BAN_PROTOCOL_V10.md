# ZC00 LLM SUBJECTIVE SCORE BAN V10

## Ban Scope
All LLM instances in any Batch (0-5) or any ZC module.

## Banned Score Types
Subjective continuous floating-point scores from LLM are FORBIDDEN.

## Detection Rule
Any output field containing "score" AND being a float generated by an LLM
inference call is a violation.

## Exceptions
- BOOL values from LLM
- ENUM values from LLM
- FACTUAL_NUMBER from LLM (e.g., "revenue: 1.5B")
- These are NOT banned because they are factual extractions

## Enforcement
verify_v40_parser_scorer_split.sh checks all zmatrix/ modules for LLM score patterns.
