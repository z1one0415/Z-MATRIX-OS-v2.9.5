# 04｜V4.0-3 Research Experiment OS

## 目标

建立研究实验操作系统。以后每一次回放、审计、修复、因子验证、报告生成，都必须有 experiment_id 和 ledger。

没有 ledger 的结果，不允许进入策略讨论。

## ExperimentLedgerItem

```python
from pydantic import BaseModel
from typing import Literal

class ExperimentLedgerItem(BaseModel):
    experiment_id: str
    experiment_name: str
    experiment_type: Literal[
        "REPLAY", "FACTOR_TEST", "REPAIR_TEST", "PAPER_REPLAY",
        "B_MATRIX_RESEARCH", "D_MATRIX_RESEARCH", "DATA_AUDIT", "REPORT_GENERATION"
    ]
    created_at: str
    created_by: str = "openclaw"
    git_commit: str
    code_version: str
    input_dataset: str
    data_snapshot_id: str | None = None
    date_range: str | None = None
    factor_version: str | None = None
    parameter_version: str | None = None
    output_report: str | None = None
    trust_level: Literal["T0", "T1", "T2", "T3", "BLOCKED", "MISSING"]
    promotion_status: str
    blocked_reason: str | None = None
    upstream_status_refs: dict = {}
    verify_script_result: str | None = None
    legacy_report_refs: list[str] = []
    production_allowed: bool = False
    real_trade_allowed: bool = False
```

## Experiment 状态

```text
DRAFT
REGISTERED
RUNNING
COMPLETED
FAILED
BLOCKED
DEPRECATED
AUDITED
```

当前阶段不得到达：

```text
PRODUCTION_CANDIDATE
```

## Append-only 规则

```text
不删除实验记录
不覆盖原记录
修正必须新增 supersede_record
每条记录必须包含 git_commit
每条记录必须包含 verify_script_result
```

## Research Workflow Registry

必须登记：

```text
REPLAY_WORKFLOW
FACTOR_TEST_WORKFLOW
REPAIR_TEST_WORKFLOW
B_MATRIX_CURRENT_SNAPSHOT_WORKFLOW
D_MATRIX_DATA_PLAN_WORKFLOW
REPORT_GENERATION_WORKFLOW
```

每个 workflow 必须声明：

```text
workflow_id
allowed_input_status
allowed_factor_trust_level
required_ledger
required_verify
production_allowed=False
```
