## DataSourceCapability

```python
from pydantic import BaseModel
from typing import Literal

class DataSourceCapability(BaseModel):
    data_source_id: str
    data_source_name: str
    coverage: str
    historical_depth: str | None = None
    pit_safe: Literal["YES", "NO", "PARTIAL", "UNKNOWN"]
    cost_level: Literal["FREE", "LOW", "MEDIUM", "HIGH", "UNKNOWN"]
    license_status: Literal["OWNED", "API_AUTHORIZED", "UNKNOWN", "NOT_ALLOWED"]
    refresh_frequency: str | None = None
    usable_for_backtest: bool = False
    usable_for_current_snapshot: bool = False
    usable_for_research: bool = True
    usable_for_paper: bool = False
    usable_for_production: bool = False
    missing_policy: Literal["BLOCK", "DATA_INSUFFICIENT", "ALLOW_PROXY", "IGNORE"] = "DATA_INSUFFICIENT"
    fallback_policy: Literal["NO_FALLBACK", "USE_PROXY", "USE_CACHE_READ_ONLY"] = "NO_FALLBACK"
```

## 初始数据源状态

```text
R price OHLCV:
  pit_safe=YES
  usable_for_backtest=True
  usable_for_current_snapshot=True
  usable_for_paper=True
  usable_for_production=False

B current financial snapshot:
  pit_safe=PARTIAL
  usable_for_current_snapshot=True
  usable_for_backtest=False
  usable_for_production=False

B historical PIT financial:
  pit_safe=UNKNOWN/NO
  usable_for_backtest=False
  status=BLOCKED

D event/flow/theme:
  pit_safe=UNKNOWN
  status=MISSING
  usable_for_backtest=False
  usable_for_current_snapshot=False

Trading cost:
  pit_safe=YES
  usable_for_backtest=True
  usable_for_paper=True
  usable_for_production=False

Broker/runtime:
  status=BLOCKED
  usable_for_production=False
```

## PIT 状态

```text
PIT_SAFE
PIT_PARTIAL
PIT_BLOCKED
PIT_UNKNOWN
```

硬规则：

```text
PIT_BLOCKED / PIT_UNKNOWN:
  usable_for_backtest=False
  promotion_status=BLOCKED_BY_PIT
```

## TTL 状态

```text
FRESH
ACCEPTABLE
STALE
MISSING
CONFLICTED
```

硬规则：

```text
STALE/MISSING/CONFLICTED → DATA_INSUFFICIENT
```
