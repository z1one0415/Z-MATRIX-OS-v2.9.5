## DSourceCapability

```python
from pydantic import BaseModel
from typing import Literal

class DSourceCapability(BaseModel):
    field_name: str
    data_source_id: str | None = None
    availability: Literal["AVAILABLE", "MISSING", "COSTLY", "PROXY_ALLOWED", "BLOCKED"]
    pit_safe: Literal["YES", "NO", "PARTIAL", "UNKNOWN"]
    usable_for_backtest: bool = False
    usable_for_current_snapshot: bool = False
    usable_for_paper: bool = False
    usable_for_production: bool = False
    access_priority: Literal["P0", "P1", "P2", "P3", "DEFERRED"]
    proxy_allowed: bool = False
    proxy_method: str | None = None
    missing_policy: Literal["BLOCK", "DATA_INSUFFICIENT", "ALLOW_PROXY"] = "DATA_INSUFFICIENT"
```

## 初始状态规则

```text
limit_up_structure:
  availability=AVAILABLE / PROXY_ALLOWED
  pit_safe=YES
  usable_for_current_snapshot=True
  usable_for_backtest=True if OHLCV sufficient

turnover_spike:
  availability=AVAILABLE / PROXY_ALLOWED
  pit_safe=YES

volume_price_divergence:
  availability=AVAILABLE / PROXY_ALLOWED
  pit_safe=YES

lhb:
  availability=UNKNOWN/MISSING unless source confirmed
  usable_for_backtest=False until source verified

block_trade:
  availability=UNKNOWN/MISSING unless source confirmed

announcement_event:
  availability=PARTIAL
  pit_safe depends on publish_time

news_catalyst:
  availability=PARTIAL
  pit_safe depends on timestamp/source

theme_heat:
  availability=MISSING/PROXY_ALLOWED

short_money_flow:
  availability=MISSING/PROXY_ALLOWED
```

## Proxy Policy

Proxy 允许，但必须标记：

```text
proxy_allowed=True
proxy_method
proxy_confidence
not_original_data=True
usable_for_production=False
```

Proxy 不得用于 production，不得伪装成原始数据。
